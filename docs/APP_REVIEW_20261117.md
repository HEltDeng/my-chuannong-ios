## 用户决定及实际修改

用户明确删除的两项是平台短信和整个 iOS 地图。腾讯云短信资质配置已停止，没有提交资质、创建凭证或购买短信套餐。

- 平台账号保留手机号加密码的注册与登录、密码二次确认、联系支持及账号注销。客户端不调用短信发送、短信找回或手机号短信验证接口；不把手机号标为已验证。
- 学生资料页展示学校认证返回的信息以及平台已有的人工核验状态，不再包含短信前置条件或人工资料提交入口。学校认证不自动等于平台人工核验通过。
- 地图入口、路由、视图、模型、地图资源、SDK链接和密钥配置均从 iOS 工程移除。服务器即使返回旧地图路由，也不能重建已移除的客户端功能。
- 未获确认许可的跑腿宣传海报不进入安装包，保存海报功能及相册写入用途声明一并移除。生产跑腿板块仍为“即将上线”。
- 系统 PhotosPicker、可选本地通知、Keychain、WidgetKit保留。课表、成绩、考试、校历、学校统一认证、已开放的校园服务继续保留。
- 官网两个 App 内入口已改为实际官网。首次协议仍由用户主动同意，拒绝时留在协议页，不调用主动退出。

生产开放配置保持原状：二手好物、失物招领、资料库、跑腿代取均为“即将上线”；其他关闭或开放状态未为审核临时切换。审核备注按当前实际可用范围说明，不把未开放的发布、举报及屏蔽流程写成已开放。

## 远程 iPhone 安装

iPhone不在开发侧Mac旁，优先采用TestFlight。用户指定的邮箱已加入专用“审核真机录屏”外部组，最终构建7已提交Beta审核并启用批准后自动通知；仅添加测试员，不授予App Store Connect管理角色，不创建公开测试链接。

1. 开发侧将最终构建加入测试组，填写测试说明及Beta审核资料并提交首次外部Beta审核。
2. Beta审核通过后发送指定测试邀请。持机人从App Store安装Apple官方TestFlight，打开邀请并安装我的川农。无需连接开发侧Mac或使用蓝牙。
3. 持机人在最新正式版iOS上测试并录屏，交回原始视频、设备型号、系统版本和实际构建号。记录须与最终送审构建一致。

TestFlight Beta审核与公开上架审核是不同流程。仅添加测试员不表示安装邀请已有可用构建，也不表示App已上架。官方依据：[外部测试与Beta审核](https://developer.apple.com/help/app-store-connect/test-a-beta-version/invite-external-testers/)、[提供测试信息](https://developer.apple.com/help/app-store-connect/test-a-beta-version/provide-test-information/)。

若后续持机人身边能用Mac连接iPhone，也可采用注册设备后的Release Testing / Ad Hoc安装，不要求App先公开上架。须取得该设备UDID并使用包含它的描述文件，App Store分发IPA不能直接安装。导出配置为 `Config/ReleaseTestingExport.plist`。官方依据：[向登记设备分发](https://developer.apple.com/documentation/xcode/distributing-your-app-to-registered-devices/)、[Apple Configurator安装](https://support.apple.com/guide/apple-configurator-mac/add-apps-to-a-device-cad4cd08c03/mac)。

## 实体设备录制顺序

录制使用有权使用的学校账号和临时平台账号，审核长期账号与演示注销的临时账号分开。学校二次验证由本人完成；不在聊天、日志或视频中显示密码。

1. 从iPhone主屏幕启动App，展示首次协议、阅读入口和同意后进入应用。
2. 展示首页、服务、我的，以及校历和校园服务。视频中没有地图入口，不演示短信。
3. 在“我的 → 我的川农账号 → 创建账号”输入昵称、手机号标识、密码和确认密码；确认后注册。退出后再用手机号与密码登录。
4. 在“我的 → 绑定学号”完成学校统一认证，展示课表、显式刷新、成绩、考试等核心流程。实际学校要求的验证码或二次验证由本人处理。
5. 展示通知设置、课表提醒和小组件等适用功能；通知按本人选择授权。
6. 展示当前未开放板块的实际“即将上线”状态，不临时开放生产业务来演示。已开放的反馈或咨询按实际页面录制；咨询意向不产生付款。
7. 用事先确定可注销的临时平台账号进入“我的 → 我的川农账号 → 注销账号”，输入当前密码，依次“申请注销”“确认注销”，展示完成后的登录状态。
8. 停止录屏，交回原始文件。出现错误先修复，再录制最终构建的完整流程。录像放入受控且无需登录即可供Apple查看的提交附件或链接后，更新Notes中的待补状态再正式重提。

[Apple屏幕录制说明](https://support.apple.com/zh-cn/102653)。本机模拟器录屏、截图与编译成功均不计作Apple要求的实体设备视频。
